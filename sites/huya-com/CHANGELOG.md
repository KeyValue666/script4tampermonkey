# 变更记录

## [0.2.1] - 2026-11-11

### 修复

- 修复 `mount()` 并发竞态：幂等检查原本在 `await waitFor('.room-core')` 之前，SPA 切房间时可能注入两个同 id 工具条。改为 `state.mounting` 占位 + await 后二次检查，`createBar()` 也加 id 复用兜底。
- 修复房间标题观察器：原来把 `MutationObserver` 存成局部变量、永不注销、标题节点异步渲染失败就永久装不上。改为存进 `state`、重建前先 `disconnect()`、用 `waitFor()` 等待标题节点、并发调用按 generation 只保留最后一次；回调加 150ms 防抖，不再每次子树变动都全文档查询。
- 原生 API 包装补还原路径：记录 `fetch` / `XHR.open/send` / `sendBeacon` / `img.src` setter / `history.pushState/replaceState` 的原始引用，用 `PATCHED` Symbol 防重复包裹，`destroy()` 按引用比对还原，不覆盖站点后续改写。
- 补统一资源登记与 `destroy()` 调试接口：监听器、观察者、定时器、`waitFor` 清理器、注入节点与 `data-s4tm-clean` 属性集中回收；`debug` 模式下可在控制台调用 `__S4TM__.destroy()`。
- 动态礼物 / 充值面板的 CSS 规则补 `:not([data-s4tm])` 排除脚本自建节点，注释如实说明这些是子串匹配而非明确类名。

### 变更

- 标题观察从「回调直接读 DOM」改为防抖后读，符合 CONVENTIONS 2.11；`countBlocked()` 的防抖定时器纳入统一登记。

## [0.2.0] - 2026-11-10

### 新增

- 性能模式（默认开启）：拦截虎牙埋点、WUP 统计、性能上报、百度统计、小程序广告与广点通广告域的请求，以及 Sentry 的 envelope / store 上报路径。
- 在 `document-start` 替换 `fetch`、`XHR.prototype.open/send`、`navigator.sendBeacon`、`HTMLImageElement.prototype.src`，命中黑名单时返回空 JSON 或静默丢弃；直播流、弹幕 WebSocket、静态资源、登录与订阅接口一律放行。
- 工具条新增「省流 N」按钮与 `Alt + P` 快捷键，实时显示已拦请求数，可一键暂停；偏好持久化。
- 隐藏礼物飘屏、跑马灯、活动横幅、播放器内推荐卡片与广告容器，减少持续占用的 DOM / 动画开销。

### 变更

- `@grant` 改为 `none`，配置从 GM 存储切换到同源 `localStorage`（网络拦截必须在页面上下文执行）。升级后两个开关回到默认值，需重新设置一次。

## [0.1.1] - 2026-11-10

### 修复

- 隐藏播放器内部由 vplayer 动态渲染的白底礼物栏 `#player-gift-wrap` 及贵族 / 充值 / 礼物信息入口，并把 `.player-wrap` 高度从 `calc(100% - 60px)` 拉回 `100%`。
- 播放器改为按 `calc(100vh - 36px)` 铺满视口高度，消除宽屏下按 16:9 宽度计算导致的下方深色留白；弹幕栏同步铺满。
- 站点原生网页全屏 / 剧场模式下播放器高度交回 `100%`，窄屏上下排列时恢复 16:9。

### 新增

- 收掉播放器内的水印、二维码、订阅、分享、举报、活动横幅等冗余浮层。

## [0.1.0] - 2026-11-10

### 新增

- 首个版本：直播间隐藏下方推荐、礼物栏、左侧边栏、顶部导航、赛事装修、广告与活动榜单，只保留视频、弹幕列表与发言输入。
- 收回站点为顶栏、侧栏、礼物栏预留的占位，播放器铺满可用宽度。
- 自建 36px 顶栏显示房间标题与主播名，支持点击或 `Alt + H` 一键还原，偏好持久化。
- 适配普通直播间与赛事直播间；站点原生网页全屏 / 剧场模式下自动让位。
