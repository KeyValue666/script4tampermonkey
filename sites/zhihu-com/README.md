# 知乎 · 净化与阅读增强

> 一句话说明：这个脚本为知乎问题页与文章页去除登录弹窗、广告和干扰卡片，并提供宽屏阅读、外链直跳、无水印原图、一键收起回答等增强体验。

| 项 | 内容 |
| --- | --- |
| 脚本文件 | [`zhihu-com.user.js`](./zhihu-com.user.js) |
| 当前版本 | `0.1.0` |
| 适配域名 | `https://www.zhihu.com/*` |
| 脚本管理器 | Tampermonkey 5.x / Violentmonkey 2.x |
| 安装 | [点击安装](https://raw.githubusercontent.com/KeyValue666/script4tampermonkey/main/sites/zhihu-com/zhihu-com.user.js) |

## 功能

所有功能都可通过右下角的齿轮按钮打开设置面板，逐项开关、即时生效并自动保存：

- **移除登录弹窗**：游客访问时自动移除登录/注册遮罩与弹窗，可正常浏览内容。
- **去除广告卡片**：移除信息流中的广告与活动推广卡片，只留真实内容。
- **宽屏模式**：隐藏问题页与文章页的右侧边栏，主内容占满整个宽度，阅读更沉浸。
- **外链直跳**：把知乎的 `/link?target=` 跳转链接还原为真实网址，点击直接打开站外页面。
- **无水印原图**：图片默认加载高清无水印原图，右键「另存为」即得干净图片。
- **展开问题描述**：问题详情默认展开，不再折叠成「阅读全文」。
- **时间置顶显示**：把每个回答的发布时间复制到回答顶部，并显示完整时间（含时分），方便判断内容是否过时。
- **一键收起回答**：右下角按钮一键收起或展开所有长回答。
- **空白处收起**：点击页面左右两侧空白区域即可收起当前回答或评论。
- **复制去版权**：复制回答内容时自动去掉末尾的「著作权归作者所有……」版权声明。

## 使用说明

1. 安装脚本后打开知乎任意问题页或文章页。
2. 页面右下角会出现一个齿轮按钮（⚙），点击即可展开设置面板。
3. 勾选/取消勾选各项功能，改动即时生效并自动保存，刷新后依然保留。
4. 「一键收起回答」开启后，右下角会出现一个 ≣ 按钮，点击在收起/展开之间切换。

快捷键 / 开关：无（全部通过设置面板操作）。

## 权限与隐私

| 项 | 内容 |
| --- | --- |
| `@grant` | `GM_getValue`、`GM_setValue` |
| `@connect` | 无 |
| 读取的数据 | 仅页面上的链接、图片、回答时间等公开内容，全部在本地处理 |
| 上传的数据 | 无 |

脚本不发起任何跨域请求，不采集、不上传任何浏览行为或页面内容。配置仅保存在浏览器本地（Tampermonkey 存储），用于记住你的开关选择。

## 已知限制

- **站点改版风险**：知乎会不定期调整页面结构（类名、选择器），部分功能（尤其去广告、时间置顶、移除登录弹窗）依赖的选择器可能失效。失效时脚本只会静默降级、不影响页面，你可在设置面板关闭对应功能。
- **SPA 路由切换**：知乎是单页应用，站内跳转后需 1–2 秒等新内容加载完成，观察器才会处理新元素。
- **「展开问题描述」为一次性动作**：仅在页面加载/路由切换时执行一次，若你手动再次折叠不会自动重新展开。
- **Safari 浏览器**：受知乎内容安全策略（CSP）限制，Tampermonkey 脚本在 Safari 上可能无法运行，建议使用 Chrome / Edge / Firefox。

## 开发说明

**实现要点**

- 脚本在 `document-idle` 时通过 IIFE 启动，`main()` 里先 `mount()` 一次，再用 `onUrlChange()` 监听知乎 SPA 路由变化，切换页面后对新内容重新执行一次性功能。
- 所有需要持续作用于动态加载内容的功能（去登录弹窗、去广告、外链直跳、无水印原图、时间置顶）统一采用「MutationObserver + 防抖定时器」模式：观察 DOM 变化，命中目标才触发处理，处理逻辑只做轻量 DOM 读写，重活经 `setTimeout` 防抖合并。
- 功能开关统一由 `settings` 内存态 + `store`（GM_getValue/GM_setValue）持久化；面板勾选时调用 `applyFeature()` 即时启停对应功能，每个可观测功能返回 `{ stop }` 用于清理观察器与定时器。

**选择器依赖**

| 用途 | 选择器 | 说明 |
| --- | --- | --- |
| 登录弹窗 | `.Modal-wrapper`、`.signFlowModal` 等 | 知乎登录组件类名，较稳定但可能随改版变化 |
| 广告卡片 | `[data-za-detail-view-path-module*="Ad"]`、`.AdvertCard` 等 | 广告带明确埋点标记，命中才移除，避免误伤 |
| 回答项 | `.AnswerItem` | 知乎回答列表项，结构相对稳定 |
| 回答时间 | `.ContentItem-time`、`[data-tooltip*="年"]` | 时间以 `data-tooltip` 承载完整值 |
| 跳转链接 | `a[href*="/link?target="]` | 知乎站外跳转统一走 `/link?target=` |

**易碎假设**

- 假设登录弹窗、广告卡片的类名与埋点属性（`data-za-*`）不随改版大面积调整；若失效需在 `setupRemoveLoginModal` / `setupRemoveAds` 中补充新选择器。
- 假设回答时间完整值存放在 `data-tooltip` 属性或元素文本中；若知乎改为异步渲染或隐藏该属性，时间置顶会拿不到完整时间。
- 假设图片去水印可通过「去掉 `_r` 后缀 + 删除水印查询参数」实现；知乎图床策略变化可能导致此方式失效。

**回归验证**

1. 打开任一知乎问题页，确认宽屏生效、登录弹窗消失、回答顶部出现发布时间。
2. 在设置面板开关「一键收起回答」，确认右下角出现/消失 ≣ 按钮。
3. 站内跳转到另一问题页再返回，确认无重复齿轮按钮、无重复面板。
4. 在 Console 执行 `document.querySelectorAll('[data-s4tm]')` 检查残留节点数量合理。
5. 关闭脚本（扩展里禁用）后刷新，确认站点恢复原样、无残留 UI。
