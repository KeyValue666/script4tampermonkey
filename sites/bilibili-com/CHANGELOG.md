# 变更记录

## [2.2.2] - 2026-11-11

### 修复

- 补统一资源登记与 `destroy()` 调试接口：监听器、`MutationObserver`、定时器、`AbortController`、objectURL、注入的 DOM 与样式集中回收；`debug` 模式下可在控制台调用 `__S4TM__.destroy()` 主动还原。`init()` / `startLayoutWatcher()` 加幂等，重复注入不再叠加观察者与监听。
- 修复 detached DOM 引用：旋转过的 `<video>`、首页轮播与网格容器在节点脱离文档后即时断开引用；`Alt + R` 找不到视频时也释放旧引用。
- `pointermove` 改为按下时缓存面板尺寸、`requestAnimationFrame` 每帧只写一次 DOM，消除拖动时的强制同步布局与掉帧。
- 单次音频提取内缓存 `__playinfo__` / `__INITIAL_STATE__` 解析结果，避免隔离世界下同一份大对象被重复解析两次。

### 变更

- `objectURL` 释放由 60 秒缩到 3 秒，句柄登记后可在卸载时提前 revoke，不再让整段音轨 Blob 长时间挂住内存。
- 音轨直链增加协议与内网地址校验（拒绝非 HTTPS、裸 IP、localhost / 内网段）；仍不做 CDN 域白名单，避免误伤 B 站动态调度的 CDN 域名。

## [2.2.1] - 2026-11-11

### 变更

- 导出音频的文件名改为与视频标题一致（`视频标题.m4a`），不再使用 BV 号，也不追加 `-audio` 后缀。
- 标题取值按优先级降级：`__INITIAL_STATE__.videoData.title` → 页面标题 DOM → 清洗后的 `document.title`；清洗 Windows 非法字符、控制字符、结尾点号并截到 80 字符，取不到时才回退 `bilibili-audio.m4a`。

## [2.2.0] - 2026-11-11

### 变更

- 重写音频提取：废弃实时录音链路，改为读取页面内嵌 `window.__playinfo__.data.dash.audio` 的独立音轨直链，一次下载完整 `m4a / AAC` 文件。秒级完成、原始码率无损、无需播放视频。
- 增加容错：隔离世界下回退解析内联 `script`；主直链失败依次尝试最多两个备用直链；页面只有 `durl` 时用官方 `playurl` 接口补查 dash 音轨；所有网络请求配 30 秒超时。
- 面板「开始录制音频」改为「提取音频」，请求期间置灰防重复点击。

### 移除

- 删除 `captureStream()` + `MediaRecorder` 实时录制逻辑，以及录制计时、切集巡检等状态机代码。

## [2.1.0] - 2026-11-11

### 新增

- 面板新增「音频提取」：一键录制当前播放视频的音频，播放结束或再次点击即自动下载 `BV号-audio.webm`（opus 编码）。实现基于 `video.captureStream()` + `MediaRecorder`，纯前端、不解析播放接口、不新增 `@grant` 权限。
- 录制中显示已录时长；切集导致 `video` 元素被替换时自动停止并保存已录部分。

### 修复

- 面板新增内容后变高，`placePanel()` 与拖拽的底部边界改为按实际面板高度计算，避免面板下半部分超出视口。

## [2.0.1] - 2026-10-29

### 变更

- 图标按钮由小电视描边图形改为小电视吉祥物：白色机身、蓝色双目与腮红的填充式内联 SVG，透明背景，无需外部图片资源。

## [2.0.0] - 2026-10-29

### 变更

- 右下角「B站工具」文字按钮替换为 B 站小电视描边图标按钮（内联 SVG，无外部资源），保留悬停上浮与按压反馈。

### 移除

- 移除面板标题栏的最小化按钮与收起正文能力：面板隐藏后可随时点击图标按钮重新打开，最小化不再是必要入口。

## [1.0.3] - 2026-10-29

### 变更

- 面板视觉优化：B 站蓝渐变标题栏与标题状态点、分层阴影、圆角微调，打开时增加淡入上移过渡。
- 「B站工具」悬浮按钮改为渐变底色，悬停上浮、按压回落，增加过渡反馈。
- 设置选项行悬停出现浅色高亮，复选框放大至 15px 并支持悬停光标。
- 尊重系统「减少动态效果」偏好（`prefers-reduced-motion`）时关闭全部动画与过渡。
- 仅调整注入 UI 的 CSS，不改动任何 DOM 结构与交互逻辑。

## [1.0.2] - 2026-10-29

### 修复

- 修正首页推荐的真实结构：轮播是 `.container.is-version8` 网格里的 `.recommended-swipe`（占 2 列 × 2 行），推荐卡片是 `.feed-card`；此前依赖的 `.bili-grid` 在当前版本已不存在，导致功能从未生效。
- 改为「隐藏轮播、让 10 张 `.feed-card` 自动回填」：容器本身是 5 列网格，轮播退出后自然形成 2 行 × 5 列，不再注入卡片、不再修改容器布局属性。
- 清零容器内 `.feed-card` 的 40px 楼层间距，修复第二行卡片被压低导致的错位。

### 移除

- 删除「按全页卡片公共祖先推断网格」与「注入轮播卡片」的整套逻辑（1.0.0 / 1.0.1 造成排版错乱与误判的根源）。

## [1.0.1] - 2026-10-29

### 修复

- 首页推荐改为只认锚点结构，识别不到就不修改样式，避免站点重绘后整页变网格。
- 站点重绘产生新节点时清理旧标记，避免类名叠加。
- 修复 `Alt + R` 在键盘事件目标不是页面元素时抛错、导致快捷键完全失效的问题。
- 修复后台标签页加载首页时布局永不应用的问题：切回前台立即补算。
- 面板隐藏后，右下角的「B站工具」按钮改为按需显示，不再常驻。

### 变更

- DOM 类名与 id 统一加 `s4tm-` 前缀，避免与站点样式冲突。

## [1.0.0] - 2026-10-29

### 新增

- 可拖拽、可最小化、可隐藏的个性化面板，配置保存在本地。
- `Alt + R` 旋转 / 恢复视频。
- 首页推荐改为 5 列并隐藏轮播图。
