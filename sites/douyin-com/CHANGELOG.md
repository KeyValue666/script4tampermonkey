# 变更记录

## [0.1.1] - 2026-11-11

### 修复

- 修复内存泄漏：`IntersectionObserver` 会强引用被观察的 video，节点移出 DOM 后从未 `unobserve`，长时间刷视频会累积无法回收的节点及其解码缓冲。现在在 MutationObserver 的 `removedNodes` 与 IO 回调里同步解除观察。
- 修复 URL 缓存设计缺陷：此前用「完整 URL」做键，抖音请求普遍带随机签名参数，缓存几乎不命中且反复填满 600 条后整表清空。改为按 `hostname + pathname` 缓存解析结果与静态判定结论，超限淘汰最早一半；`AD_QUERY_RE` 仍按原始 query 判断。
- 修复 DOM 清理的性能反噬：此前每个新增节点都执行一次 `querySelectorAll`，弹幕高速滚动时会持续占满空闲时间，并且没有节点时也调度空任务。现在跳过弹幕容器整棵子树、叶子节点不深扫、每批最多 24 次子树扫描、无待处理节点不调度。
- 修复 React 虚拟列表复用卡片导致的误隐藏：`data-s4tm-ad` 标记每批按角标复核，角标消失即撤除；自动跳过改按当前视频 id 去重，换一条新广告仍能再跳，也不会对复用后的正常视频重复点击。
- 修复直播模式 CSS 可能连带隐藏弹幕区：子串规则改用 `:is(...)` 并排除 `chatroom` / `chat` / 可编辑节点；信息流直播卡片的隐藏限定在 `#slidelist` 内，避免误伤点开的直播间弹层；移除会命中弹幕礼物消息的 `webcast-chatroom___gift` 规则。
- 修复被拦 XHR 的伪响应不完整：补 `responseURL`、`getAllResponseHeaders`、`getResponseHeader`，否则站点调用原生方法会因内部状态不一致抛 `InvalidStateError`；`fetch` 的空响应兜底对象补 `headers` / `statusText` / `clone`。
- 修复黑名单长连接的哑通道原型丢失：`WebSocket` / `EventSource` / `Notification` 的替身现在继承原生 prototype，站点的 `instanceof` 判断不会走异常分支。
- 移除 `rel=prefetch` 不再计入「省流 N」，避免暂停省流后计数仍上涨；预取移除仍由省性能开关控制。

### 变更

- 推荐流响应先做广告字段字符串预检，没有广告字段就不再整包 JSON 解析与序列化；列表改用倒序 `splice` 删除，避免展开超大数组触发参数数量上限；opaque 响应直接放行。
- XHR 响应缓存改为只存短指纹与过滤结果，超过 256KB 的响应不缓存；广告计数按 XHR 实例去重。

## [0.1.0] - 2026-11-11

### 新增

- 首个版本：抖音网页版（`www.douyin.com` / `live.douyin.com`）清爽与省流脚本。
- 在 `document-start` 接管 `fetch`、`XMLHttpRequest`、`sendBeacon`、图片 / 脚本 / iframe / link 的资源地址赋值、`setAttribute`、`WebSocket`、`EventSource` 与 `Notification`：埋点、监控、性能上报、广告域与推广接口一律不发请求；被拦的 fetch 返回空 JSON，被拦的 XHR 伪造成功回调，避免站点等待上报卡住。视频分片、弹幕长连接、评论、登录与静态资源全部放行。
- 改写推荐流、关注流与搜索结果响应，剔除带 `is_ads` / `is_ad` / 非空 `ad_info` 的广告条目，从数据源头避免广告视频下载。
- 按广告角标、营销短文案与语义属性隐藏推广卡片、下载 / 充值入口、营销弹窗与信息流直播卡片；当前视频为广告时自动静音并切下一条。
- 直播模式隐藏顶部导航、榜单、礼物、电商、活动与推荐位，只保留画面与弹幕互动（含发言框、发送按钮、弹幕与清晰度设置）。
- 性能控制：移除纯预取节点、降低自动预加载、暂停离屏视频、停掉礼物飘屏 / 跑马灯 / 动效横幅的动画与绘制、屏蔽通知权限申请。
- 右下角工具条显示模式、拦截数与剔除广告数，提供清爽 / 省流 / 省性能 / 跳广告四个独立开关与 `Alt + H` / `Alt + P` / `Alt + O` / `Alt + K` 快捷键，偏好持久化；一键还原站点原界面。
