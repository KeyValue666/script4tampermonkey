# 变更记录

## [0.2.1] - 2026-11-19

### 修复

- 开关网格最后一个按钮只剩一个圆点、看不出用途：规则按钮改为独占一行的「规则设置 / 规则收起」文字按钮，不再当作第 6 个状态灯。
- 规则清单出现多行只有 `×`、点了没反应：预建空行的 `display:flex` 盖掉了 `[hidden]` 的浏览器默认样式。改为清单行完全按需创建、并给 `[hidden]` 显式加 `display:none`，从此每一行都有文字且 `×` 都能删除。

### 变更

- 规则面板重排为「当前视频」「已保存规则」两个分区，标题带条数；动作按钮用浅底与状态开关区分，添加按钮用绿色主色。展开 / 收起都会重算自动避让。

## [0.2.0] - 2026-11-19

### 新增

- 自定义屏蔽（默认关闭，`Alt + M`）：按关键词（作者名全等 / 文案与话题包含）或作者 ID 屏蔽信息流内容，在推荐流响应里剔除并在 DOM 层兜底打标记。规则本地保存，面板可逐条增删。
- 手动标记与放行闭环：当前视频可标记广告、本条放行、屏蔽作者、加白名单；白名单与放行优先于广告与屏蔽判定。跳过广告 / 命中屏蔽后出现 5 秒撤销条，点「放行」即可加回。
- 工具条新增第五个「屏蔽」开关与「规则」按钮，展开后是四个动作 + 关键词输入 + 规则清单；统计条增加「筛 K」计数。

### 变更

- 推荐流过滤从「只剔广告」升级为「广告 + 用户规则」，返回结构拆成 `ads` / `filtered` 两个计数；无规则时保留原来的快速预检，不给每条内容构造匹配对象。
- 手动标记的广告按稳定视频 ID 匹配，即使响应没有广告字段也会剔除；改用数组持久化 + Set 索引 O(1) 查找，五类规则均有数量上限，畸形存储逐条校验不崩溃。

## [0.1.5] - 2026-11-14

### 变更

- 盾牌图标与折叠圆点由抖音红改为正向绿（`#2dd36f`），深底页面依旧高对比、显眼，且语义上对应「已防护」。计数徽标文字同步由红转绿。工具条整体不再出现红色。

## [0.1.4] - 2026-11-14

### 变更

- 工具条从一字排开的横条改为卡片式三行布局：标题行（盾牌图标 + 模式 + 收起按钮）、统计条（`拦 N` / `去广告 M` 左右分布）、2 × 2 开关网格。宽度固定 220px（窄屏 200px），比原横条更窄，配合自动避让更不容易遮挡输入区。
- 折叠圆点的 `▸` 字符换成内联 SVG 盾牌 + 勾（对应「拦截 / 防护已开启」场景），展开态收起按钮换成双右箭头 SVG；两个图标按 `data-s4tm-collapsed` 用 CSS 切换显隐，不加载外部资源、不依赖字体。
- 配色对齐抖音品牌色：折叠圆点抖音红、开关开启态抖音青高亮并带前缀状态圆点、关闭态暗灰，统计条青 / 粉双色。刻意不加 `backdrop-filter`，避免持续占用 GPU。
- `updateBar()` 改为只更新 `aria-label` / `title` 与两个统计子节点，不再写收起按钮的 `textContent`（那会清掉 SVG 子节点）。统计文本由单条拆成两块分别更新。
- 0.1.3 的折叠展开修复、容器级 `click` 兜底与指针捕获时机全部保留并回归验证。元数据头部未改动，DEV 代理壳无需重装，刷新网页即生效。

## [0.1.3] - 2026-11-14

### 修复

- 修复「收起后再也打不开」：折叠态在圆点按钮上 `setPointerCapture` 会把后续 `click` 重定向到工具条容器，按钮收不到点击。改为按钮上按下不捕获、只有确认是拖动（位移 > 3px）才补捕获并在抬手时释放；另在容器上挂 `click` 兜底（仅折叠态、未拖动、目标是容器本身时展开），覆盖浏览器差异。
- 修复折叠圆点在深色页面上不显眼：改为 40px 抖音红圆点，白描边、外发光、白色加粗箭头，右上角白色徽标实时显示已拦请求数（超过 999 显示 `999+`）。
- 折叠态按钮的 hover 样式改用更高特异性选择器，避免被通用 `.s4tm-toggle:hover` 的灰底盖住红色。

### 变更

- `updateBar()` 同步写 `data-s4tm-count` 供 CSS 伪元素显示。元数据头部未改动，DEV 代理壳无需重装，刷新网页即生效。

## [0.1.2] - 2026-11-14

### 修复

- 修复右下角工具条遮挡评论输入框、弹幕发言框与发送按钮：检测到输入控件与工具条默认位置重叠时自动上移到输入区上方；用「默认位置虚拟矩形」判定相交，避免上移后又掉回去的抖动，并把结果限制在视口内。
- 避让测量走空闲任务并做 400ms 节流，聚焦输入框 / 折叠 / 路由切换时强制重测；弹幕高频插入不会每批都做一次全文档测量。
- 工具条新增「收起」按钮与 `Alt + B`：折叠成 30px 小圆点，彻底不占输入区，折叠状态持久化。
- 工具条支持拖动与双击复位，位置持久化。位移超过 3px 才算拖动，单击开关按钮不会误关自动避让；pointermove 用 rAF 合并、尺寸只在按下时读一次、抬手取消未执行的帧，避免高频布局读取和悬挂回调。
- 窄屏工具条底距统一为 12px，与避让算法的虚拟矩形基准一致。

### 变更

- 本地存储新增 `s4tm:douyin-com:barCollapsed`、`barPos` 两个键。元数据头部未改动，DEV 代理壳无需重装，刷新网页即生效。

## [0.1.1] - 2026-11-11

### 修复

- 修复内存泄漏：`IntersectionObserver` 会强引用被观察的 video，节点移出 DOM 后从未 `unobserve`，长时间刷视频会累积无法回收的节点及其解码缓冲。现在在 MutationObserver 的 `removedNodes` 与 IO 回调里同步解除观察。
- 修复 URL 缓存设计缺陷：此前用「完整 URL」做键，抖音请求普遍带随机签名参数，缓存几乎不命中且反复填满 600 条后整表清空。改为按 `hostname + pathname` 缓存解析结果与静态判定结论，超限淘汰最早一半；`AD_QUERY_RE` 仍按原始 query 判断。
- 修复 DOM 清理的性能反噬：此前每个新增节点都执行一次 `querySelectorAll`，弹幕高速滚动时会持续占满空闲时间，并且没有节点时也调度空任务。现在跳过弹幕容器整棵子树、叶子节点不深扫、每批最多 24 次子树扫描、无待处理节点不调度。
- 修复 React 虚拟列表复用卡片导致的误隐藏：`data-s4tm-ad` 标记每批按角标复核，角标消失即撤除；自动跳过改按当前视频 id 去重，换一条新广告仍能再跳，也不会对复用后的正常视频重复点击。
- 修复直播模式 CSS 可能连带隐藏弹幕区：子串规则改用 `:is(...)` 并排除 `chatroom` / `chat` / 可编辑节点；信息流直播卡片的隐藏限定在 `#slidelist` 内，避免误伤点开的直播间弹层；移除会命中弹幕礼物消息的 `webcast-chatroom___gift` 规则。
- 修复被拦 XHR 的伪响应不完整：补 `responseURL`、`getAllResponseHeaders`、`getResponseHeader`，否则站点调用原生方法会因内部状态不一致抛 `InvalidStateError`；`fetch` 的空响应兜底对象补 `headers` / `statusText` / `clone`。
- 修复黑名单长连接的哑通道原型丢失：`WebSocket` / `EventSource` / `Notification` 的替身现在继承原生 prototype，站点的 `instanceof` 判断不会走异常分支。
- 移除 `rel=prefetch` 不再计入「省流 N」，避免暂停省流后计数仍上涨；预取移除仍由省性能开关控制。

### 变更

- 推荐流响应先做广告字段字符串预检，没有广告字段就不再整包 JSON 解析与序列化；列表改用倒序 `splice` 删除，避免展开超大数组触发参数数量上限；opaque 响应直接放行。
- XHR 响应缓存改为只存短指纹与过滤结果，超过 256KB 的响应不缓存；广告计数按 XHR 实例去重。

## [0.1.0] - 2026-11-11

### 新增

- 首个版本：抖音网页版（`www.douyin.com` / `live.douyin.com`）清爽与省流脚本。
- 在 `document-start` 接管 `fetch`、`XMLHttpRequest`、`sendBeacon`、图片 / 脚本 / iframe / link 的资源地址赋值、`setAttribute`、`WebSocket`、`EventSource` 与 `Notification`：埋点、监控、性能上报、广告域与推广接口一律不发请求；被拦的 fetch 返回空 JSON，被拦的 XHR 伪造成功回调，避免站点等待上报卡住。视频分片、弹幕长连接、评论、登录与静态资源全部放行。
- 改写推荐流、关注流与搜索结果响应，剔除带 `is_ads` / `is_ad` / 非空 `ad_info` 的广告条目，从数据源头避免广告视频下载。
- 按广告角标、营销短文案与语义属性隐藏推广卡片、下载 / 充值入口、营销弹窗与信息流直播卡片；当前视频为广告时自动静音并切下一条。
- 直播模式隐藏顶部导航、榜单、礼物、电商、活动与推荐位，只保留画面与弹幕互动（含发言框、发送按钮、弹幕与清晰度设置）。
- 性能控制：移除纯预取节点、降低自动预加载、暂停离屏视频、停掉礼物飘屏 / 跑马灯 / 动效横幅的动画与绘制、屏蔽通知权限申请。
- 右下角工具条显示模式、拦截数与剔除广告数，提供清爽 / 省流 / 省性能 / 跳广告四个独立开关与 `Alt + H` / `Alt + P` / `Alt + O` / `Alt + K` 快捷键，偏好持久化；一键还原站点原界面。
